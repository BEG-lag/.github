# Seguridad / Security

**Español.** Si encuentras una vulnerabilidad, no abras un issue público. Repórtala en privado desde la pestaña **Security** del repositorio, con el botón **Report a vulnerability**, o escribe a beg.empleos@gmail.com. Incluye qué repositorio, cómo reproducirla y qué impacto tiene. Respondo en cuanto pueda y aviso cuando quede corregida.

Las apps web de estos repositorios (por ejemplo facturas-cfdi, finiquito-mx, hoy-circulo) corren en tu navegador y no tienen servidor ni guardan datos fuera de tu dispositivo; aun así, cualquier forma de sacar datos del navegador o de ejecutar código ajeno es un reporte bienvenido.

**English.** Please do not open a public issue for a vulnerability. Report it privately from the repository's **Security** tab (**Report a vulnerability**) or by email to beg.empleos@gmail.com, with the repository, steps to reproduce and impact. The web apps here run entirely in your browser with no server; any way to exfiltrate data or inject code is still very welcome as a report.
